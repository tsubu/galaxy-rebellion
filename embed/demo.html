フロントページにブラウザゲームを埋め込んだサンプルです。ゲームはクリックするまで読み込まれないため、ページの表示速度には影響しません。

ここに最新スコアが表示されます（イベント連携のデモ）

軽い

ポスター画像は CSS のみ。クリックされて初めてゲーム本体（three.js）を読み込みます。

邪魔しない

画面外にスクロールすると自動でポーズ・描画停止。キー操作はゲームをクリックした時だけ有効です。

連携できる

開始・ステージクリア・結果のイベントを受け取れます。キャンペーンや計測にどうぞ。

このページで使っているコード

<div data-galaxy-rebellion data-ratio="16/10" data-radius="14"></div>
<script src="galaxy-rebellion.js" defer></script>

<script>
  document.addEventListener('galaxyrebellion:result', (e) => {
    const { score, stage, win } = e.detail;
    console.log(score, stage, win);
  });
</script>
